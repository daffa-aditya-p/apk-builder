# APK Builder - Quick Start Guide

## 🚀 Quick Installation (Termux)

```bash
# Clone repository
git clone https://github.com/daffa-aditya-p/apk-builder.git
cd apk-builder

# Run installation script
chmod +x install.sh
./install.sh

# Run the tool
./build-apk
```
